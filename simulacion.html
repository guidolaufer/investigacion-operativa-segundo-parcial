Simulación Monte Carlo

Procedimiento con dos dársenas

  1. Convertí los números aleatorios a tiempos entre llegadas y tiempos de servicio usando la distribución que indique el ejercicio.
  2. Hora de llegada i = llegada anterior + tiempo entre llegadas i.
  3. Elegí el servidor que quede disponible antes; con FIFO respetá el orden de llegada.
  4. Inicio de servicio = máximo(hora de llegada, próxima disponibilidad del servidor elegido).
  5. Salida = inicio + duración del servicio.
  6. Espera = inicio − llegada; permanencia = salida − llegada.
  7. Actualizá disponibilidad de la dársena asignada y repetí.

Generación de tiempos exponenciales

Si el enunciado pide tiempos exponenciales y entrega números uniformes U entre 0 y 1, se puede aplicar la transformación inversa:

Tiempo entre llegadas = −ln(1−U)/λ
Tiempo de servicio = −ln(1−U)/μ

También es válido −ln(U)/tasa para U uniforme continuo; seguí la convención de tu cátedra. Si el examen proporciona una tabla discreta de intervalos de aleatorios, usá esa tabla en vez de imponer una exponencial.

Indicadores

Espera media = Σ esperas / número de camiones
Permanencia media = Σ permanencias / número de camiones
Utilización de cada dársena = tiempo ocupado / horizonte observado × 100%

Definí explícitamente el horizonte: desde tiempo 0 hasta la última salida, o el horizonte fijado por el examen. No confundas utilización por servidor con utilización global.
